# Central Circle Remote

Central Circle-branded remote support client for Windows.

## Product identity

- Product name: Central Circle Remote
- Publisher: Central Circle
- Website: https://www.centralcircle.co.za
- Primary colours: blue, black and white
- Accent colour: light blue

## Build approach

This repository stores Central Circle branding, configuration, build automation and source modifications. Windows releases will be produced by GitHub Actions so a local development computer is not required.

Sensitive server addresses, access keys and signing credentials are not stored in this public repository.

## Status

Repository connected and branding setup started on 1 September 2026.
